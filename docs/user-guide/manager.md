# Workshop manager

You keep jobs moving, assign work, decide exceptions and check quality.

## Start of day: the dashboard

The **Dashboard** shows a strip of counts: received today, open jobs, **overdue**,
**awaiting approval**, **awaiting parts** and **ready for collection**. Each count opens the
matching job list. **Overdue** means past the promised time.

## Assigning work

On a job card, **Assign mechanic** (more than one if needed). Only staff with mechanic
access at that branch can be assigned. **Unassign** if plans change; the history is kept.
Set **priority** (Low, Normal, High, Urgent) in **Edit job details**; lists sort by
priority and promised time.

The **Appointments** page and **Reports → Operations → Mechanic workload** show who has
what.

## Moving jobs on

Each job shows the allowed next steps. Typical path:

**Send for inspection → Start diagnosis → Send for customer approval → (Waiting for parts)
→ Start repair → Send to quality check → Ready for collection → Hand over vehicle.**

Every change is recorded with your name and time in the job's status history.

When the customer approves a quotation, the job stays in **Awaiting quotation approval**
until you release it with **Start repair** (or **Waiting for parts**), so you decide when
it goes back into the workshop.

## Approval exceptions

If work must start before a quotation is approved — the customer approved verbally,
warranty work, internal no-charge work, or a safety emergency — use **Authorise work
without quotation approval**. Choose the type, describe exactly what work is authorised
and why. The exception is recorded with your name and can be revoked. Use this sparingly;
it is reviewed in the audit log.

## Quality inspection

When a job arrives in **Quality inspection**, **Start inspection** with the quality
checklist, test-drive where relevant, and submit. If it passes, mark **Ready for
collection** (the customer is told). If not, move it back to repair with a note.

## Cancelling a job

**Cancel job** asks for a reason. Reserved parts are released automatically. Issued
invoices are not affected; accounts handle any refund or credit.

## Reports

**Reports → Operations** for a chosen period: jobs received and completed, turnaround
(average and median), open and overdue jobs, quotation approval rate, mechanic workload.
**How these figures are calculated** explains each figure.
